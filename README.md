## FAQ

### What is XCutors?

XCutors is a bundled collection of popular Roblox script executors (Volt, Synapse Z, Potassium, Wave) along with a universal loader, designed for Windows users who want easy access to multiple tools in one package.

### Is XCutors free to use?

Yes, XCutors itself is free and open-source. However, some individual executors included in the pack may have their own licensing or access requirements – please check each executor's official page for details.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Both 32-bit and 64-bit editions are compatible, though 64-bit is recommended for best performance.

### Why is my anticomponent flagging the files?

Script executors use code injection techniques that are often flagged by anticomponent software as potentially unwanted programs (PUPs). This is a false positive for legitimate executor tools. You may need to add an exception in your anticomponent settings.

### How do I update XCutors?

Simply download the latest release from the GitHub Releases page and replace the old files. Your saved scripts and preferences in the 'userdata' folder will be preserved.

### Can I use XCutors on Mac or Linux?

No, XCutors is built exclusively for Windows. Roblox script executors rely on Windows-specific APIs for injection, so cross-platform support is not available.

### What scripts are included in the built-in library?

The built-in script hub includes popular utility scripts for games like Blox Fruits, Pet Simulator X, Murder Mystery 2, and general-purpose scripts such as ESP, speed modifiers, and UI libraries. The library is updated regularly.

### Which executor should I choose?

It depends on your needs: Volt is known for speed and stability, Synapse Z has extensive API support, Potassium is lightweight and beginner-friendly, and Wave offers advanced debugging features. You can switch between them anytime using the loader.

### I'm getting an injection error – what should I do?

First, ensure Roblox is running and you're in a game (not just the launcher). Run XCutors as Administrator. If the issue persists, try restarting both Roblox and the executor, or check the GitHub Issues page for known problems with the current Roblox version.

### Where can I find more scripts?

In addition to the built-in script hub, popular community resources include script-sharing forums, GitHub repositories, and Discord servers dedicated to Roblox scripting. Always scan scripts from unknown sources before executing them.
